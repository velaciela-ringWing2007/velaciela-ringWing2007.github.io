# 攻撃監視コンソール（Threat Map）

攻殻機動隊っぽいサイバー攻撃監視画面を、ブラウザだけで眺めて楽しむための **1枚もの HTML**。
世界地図に攻撃線がビュンビュン飛んで、着弾するたびに標的拠点でリングが広がる。あのニュースでよく見るやつ。

> ⚠️ これは **可視化の演出（シミュレーション）** です。実際にどこかを攻撃したり、本物の通信を観測したりはしません。攻撃イベントはすべてブラウザ内でランダム生成しています。

## できること

- 🗾 **日本中心の世界地図**（正距円筒図法）＋ 本物の大陸ドット
- 🎯 **16拠点を標的に選べる**（複数同時OK）
  - 国内: 東京 / 札幌 / 横浜 / 名古屋 / 大阪 / 福岡
  - 海外: NY / ロンドン / モスクワ / シンガポール / シドニー / 平壌 / ソウル / 上海 / デリー / フランクフルト
- ◆ **HQ（自拠点）を選べる** … 標的とは別に「自分がいる拠点」を指定。地図の中心は常にHQ、菱形マーカー付き。HQ宛の着弾はフィードで赤く強調
- 🎲 **RANDOM** … 全拠点からランダムに狙われる
- 🔁 **RETALIATE（報復）** … 着弾の一部が攻撃元へ逆向きに反撃（緑の線）
- 🩸 **攻殻MAXモード** … 配色を赤基調に切り替え
- 🖥️ **コマンドコンソール** … `nmap osaka` などで HQ から能動的に線を飛ばせる
  - 自分の攻撃は専用色の点線＋コマンド名付きで飛び、着弾点に照準マーカーが数秒残る
- 🤖 **防衛支援AI〈ククリ〉** … 選択肢式の人工無能アシスタント
  - 選択肢から次の選択肢へ分岐（攻撃元の国別レポート / HQ移動 / 設定変更 / 雑談）。「もどる」「メニュー」で戻れる
- 📺 **見るだけモード** … ヘッダーの「見るだけ」で地図と Live Feed を画面いっぱいに表示。設定・コンソール・ククリは右下の「▲ 操作パネル」で下から出せる。「全画面」ボタンも付いている（ショートカット: `V` 見るだけ / `F` 全画面 / `Esc` パネルを閉じる）
- 📅 **日替わりリセット** … 累計は日付が変わると 0 に戻る（localStorage）
- ⚙️ 標的・モード・各設定は localStorage に保存され、次回も復元

## コマンド一覧

コンソールに入力して Enter。地名は部分一致でOK（`osa` → 大阪）。
どのコマンドも `-h` / `--help` で使い方を表示（`help <コマンド>` でも可）。オプションは `-n 5` / `-n5` / `--top 5` / `--top=5` のどれでも書けます。

| コマンド | 動作 |
|---|---|
| `help [コマンド]` | コマンド一覧 / 個別の使い方 |
| `ls` / `targets` | 標的拠点の一覧（`-s`: 今日の送信元都市を件数順に） |
| `status` | 現在の統計 |
| `hq` / `hq <地名>` | 自拠点(HQ)の表示 / 変更 |
| `nmap [-c N] <地名>` | 指定地点をスキャン（HQから線を飛ばす）。`-c` で回数（1〜10） |
| `ping` / `curl` / `ssh` / `hydra` / `attack` / `strike` | 同上（演出） |
| `scan [オプション]` | まとめてスキャン（下表） |
| `defend [-w SEC]` | 直近にHQを攻撃してきた相手へ一斉反撃。対象時間は「反撃対象」の設定値（5秒〜5分、初期値5秒）、`-w` で今回だけ変更 |
| `history` / `date` / `whoami` | 入力履歴 / 現在時刻 / 自分の情報 |
| `clear` | 画面クリア |

### scan のオプション

| オプション | 対象 |
|---|---|
| （なし） | 直近にHQを攻撃してきた相手（一斉反撃と同じ） |
| `-a`, `--all` | 全拠点 |
| `-t`, `--targets` | 選択中の標的 |
| `-c`, `--country CC` | 指定国の送信元都市（例: `scan -c RU`） |
| `-n`, `--top N` | 今日の件数上位N都市（1〜20） |
| `-w`, `--window SEC` | オプションなしのときの対象時間を今回だけ変更（1〜3600秒） |

`-a` / `-t` / `-c` / `-n` は同時に指定できません。

（↑↓キーでコマンド履歴、Tab でコマンド名・オプション・地名を補完）

## 技術メモ

- **完全に静的な 1 ファイル。** 外部 JavaScript ライブラリは一切なし（D3 等も未使用）。世界地図の描画・投影も Canvas 2D で自前実装。
- 唯一の外部参照は **Google Fonts**（Rajdhani / Share Tech Mono）。読み込めない環境でもシステムフォントにフォールバックするので表示は壊れません。
- サーバ不要。ファイルを開くだけで動きます。

### ファイル構成

```
threat-map/
├─ index.html   本体（HTML/CSS/JS/大陸データ すべて同梱）
└─ README.md
```

大陸ドット（約3,800点 / 2度グリッド）は `index.html` 内にインライン済みなので、このファイル単体で完結します。

## データソースの差し替え

攻撃イベントは「送信元・宛先・プロトコルを持つ行」を線に変換しているだけです。
外部からイベントを流し込みたい場合は、次の口を叩きます:

```js
window.ATTACK.push({
  srcLat: 55.75, srcLng: 37.6,   // 送信元の緯度経度
  cc: "RU", label: "Moscow",      // 国コード / 表示名
  proto: "SSH", port: 22,         // プロトコル / ポート
  ip: "203.0.113.45"              // 表示用IP
});
```

将来 T-Pot などの実ログを流す場合は、ローカルで動かして WebSocket やファイル読み込みでこの口に繋ぐ想定です
（※GitHub Pages 上の静的ページからは外部通信できないため、実データ連携はローカル実行が前提）。

## 今後やりたいこと（サーバが必要な組）

静的ページの範囲では作れないため、別途バックエンドが要るもの:

- 攻撃側 vs 防衛側の **リアルタイム対戦**（WebSocket サーバ）
- **本物の T-Pot 連携**（実ログの取り込み）
- 複数人で **同じ統計を共有**（DB / サーバ）
