# うんちキャッチ（Unchi Catch）

上をくるくる➰飛び回るネズミ🐁が落としてくる💩を、ペンギン🐧が🍚と🧹を持ち替えながらさばく、インベーダーっぽいミニゲーム。
ビルド不要の **1枚もの HTML**（外部ライブラリなし）。

```
🐁➰💩➰➰


　　　🍚🐧
```

## デモ

https://velaciela-ringWing2007.github.io/unchi-catch/

## ルール

- 制限時間は 60 秒。終了時の **合計（飯pt ＋ 箒pt）** がスコア
- 手に持っているのは 🍚（ご飯）か 🧹（箒）のどちらか。いつでも持ち替えられる

| できごと | ポイント |
| --- | --- |
| 🍚 を持っている間 | 飯pt が毎秒 +10 |
| 🧹 で 💩 をキャッチ | 箒pt +30 |
| 🍚 に 💩 が入る | 飯pt −60 |
| 🐧 本体に直撃 | 箒pt −80 |
| 💩 が地面に落ちる | ±0 |

🧹 を持っている間は飯pt が貯まらないので、いつ持ち替えるかが勝負。

## 遊び方いろいろ

- 🍚 **ひたすら避けて飯pt を地道に稼ぐ**
- 🧹 **💩 キャッチ狙いで箒pt を稼ぐ**
- 🐧 **直撃狙いでマイナス最高点を目指す**

## 難易度

| 難易度 | ネズミ | 💩 の間隔 | 落下速度 |
| --- | --- | --- | --- |
| 初級 | 1匹 | ゆっくり | 遅い |
| 中級 | 2匹 | ふつう | ふつう |
| 上級 | 3匹 | 速い | 速い |

## 操作

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 左右移動 | `←` `→` / `A` `D` | 画面下の ◀ ▶ を長押し |
| 🍚 ⇄ 🧹 持ち替え | `Space` / `↑` / `W` | 真ん中のボタン |
| 一時停止 | `Esc` / `P` | （タブを切り替えると自動で一時停止） |

## その他

- 難易度ごとのハイスコアは localStorage に保存（ブラウザのデータを消すとリセット）
- 点数・難易度のバランスは `index.html` のスクリプト冒頭にある `PT` と `DIFF` で調整できる
- 絵文字の見た目は OS / ブラウザのフォントによって変わります
