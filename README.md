## ⏱️ カウントダウンタイマー

https://velaciela-ringWing2007.github.io/countdown-timer/

日常の様々なイベントまでの残り時間をリアルタイムで表示します。

### 機能

- **複数タイマー同時表示** - 起床時刻、勤務開始、定時退勤、就寝時間など
- **4種類のタイマー形式**
  - 毎日（例: `08:20:00`）
  - 毎週（例: 月曜 09:00）
  - 毎月（例: 25日 18:00）
  - 特定日時（例: `2024-01-01T00:00:00`）
- **グループ機能** - 複数のタイマーセットを切り替え可能
- **視覚的なアラート** - 残り時間に応じて色変化・点滅
- **エクスポート/インポート** - JSONファイルでバックアップ

### 設定例

```json
{
  "active": 0,
  "groups": [
    {
      "name": "仕事用",
      "timers": [
        {"title": "起床時刻", "targetTime": "08:20:00"},
        {"title": "定時まで", "targetTime": "18:00:00"}
      ]
    }
  ]
}
```

## 🎨 いろ まぜまぜ

https://velaciela-ringWing2007.github.io/color-mixer/

子供向けの色合成アプリ。色を選んでドラッグし、重ねて混ざる様子を遊びながら学べます。

### 機能

- **ひかりの いろ（加法混色）** - 黒背景に赤・緑・青の光源を重ねる。重なると明るくなる（赤+緑=黄、3つで白）
- **いろガラス（減法混色）** - 白背景にシアン・マゼンタ・イエローの色ガラスを重ねる。重なると暗くなる（水色+黄=緑、3つで黒）
- **えのぐ（顔料混色）** - 白い紙に赤・黄・青の絵の具を重ねる。絵の具らしく混ざる（赤+黄=橙、黄+青=緑、赤+青=紫、3つで茶）。RYBモデルでキャンバスに描画
- **3げんしょく ⇄ 12いろ 切り替え** - 各モードで「三原色だけ」か「色鉛筆の代表12色」を選べる
- **ドラッグ操作** - タップで色を出し、指/マウスで重ねる（光/ガラスは `mix-blend-mode`、絵の具はキャンバス計算で混色）
- ダブルタップで1つ消す / ぜんぶ けす・さいしょから ボタン

## 🔬 ひかりの じっけん

https://velaciela-ringWing2007.github.io/light-lab/

子供向けの光の実験アプリ。光源・鏡・物などをドラッグして、光のふるまいを遊びながら学べます。

### 機能

- **かがみ（直進・反射）** - 光はまっすぐ進み、鏡で「入射角＝反射角」で反射。複数の鏡で何度もバウンド
- **プリズム（分散）** - 白い光がプリズムで屈折し、7色の虹に分かれる（スネルの法則で計算）
- **かげ（影）** - 光源と物で影ができる。光源を動かすと影が伸び縮み・移動。影ができる理由（光の直進）を線で表示
- Canvas描画＋ドラッグ操作。各モード「さいしょから」でリセット

## 💨 くうきの ながれ

https://velaciela-ringWing2007.github.io/airflow-lab/

子供向けの流体シミュレーション。空気の流れを線で見ながら「なぜ浮くの？」を体験できます。

### 機能

- **ふうせん（送風機／ベルヌーイ）** - 上向きジェット気流に物体が浮く。横にズレても速い空気側（低圧）に引き戻されて中心に戻る。空気は止まった流線で表示し、物体の周りで曲がり・上で渦を巻く。物体をドラッグして浮く位置を探せる。「ふうりょく」スライダーで風の強さを 0.2×〜20× に変えられ、上げすぎると“ありえない風速”で物体が勢いよく飛んでいく。「あつりょくを みる」で全方位の正圧(赤)／負圧(青)リング、「ちからを みる」で力の矢印（どちらもボタンでON/OFF）
- **つばさ（翼の揚力）** - いわゆる翼型（キャンバー付き）まわりの止まった流線。風は常に水平。前縁で空気が上下に分かれ（よどみ点）、上面は速く流れ下面は翼に沿って下へ押される（ダウンウォッシュ＝揚力の反作用）。迎え角をドラッグで変えると流れと揚力が変わり、上げすぎると上面後方が剥離して渦（グルグル）を巻く（失速）。「ふうりょく」スライダーで風速を変えると流れが速く（色が赤く）・揚力が大きくなる
- 流線はドラッグに追従して引き直す。物理定数・幾何はNodeで検証済み

## 🔊 おとの なみ

https://velaciela-ringWing2007.github.io/sound-lab/

子供向けの波動・音響シミュレーション。音を「波」として見ながら「なぜ聞こえるの？」を体験できます。

### 機能

- **はもん（波紋・干渉）** - 2次元波動方程式の離散グリッド（高さ場u・速度場v＋減衰）でリアルタイム伝播。最初から音源2つで「明るいしま＝強め合い／暗いすじ＝打ち消し合い」の干渉縞を可視化。画面タップで波紋、「おんげん」で連続発振源を1〜2個の配置／除去、「かべ」で反射板（鏡）を配置。たかさ（周波数）・おおきさ（振幅）スライダー付き
- **ドップラー（救急車）** - 動く音源🚑が画面を横切り、進行方向の前は波面が詰まって高い音（赤）、後ろは伸びて低い音（青）になる様子を可視化。Web Audio APIで実際の音程変化も連動（ON/OFF）。速さを上げて音速を超えると波面が円錐状に重なりソニックブーム（マッハ表示）
- **こえ（マイク・オシロスコープ）** - マイク許可で声の波形（上）と周波数スペクトル（下）をリアルタイム描画。未許可の間はデモ波形（マイク音声は出力につながず録音・送信もしない）
- Canvasのオフスクリーン・グリッド描画で軽量。サーバ送信なし・すべてブラウザ内で計算

## 🎢 ころころ ジェットコースター

https://velaciela-ringWing2007.github.io/coaster-lab/

子供向けの力学・エネルギー保存シミュレーション。レールの上を転がる玉で「なぜ速くなるの？」「どうして飛ぶの？」を体験できます。

### 機能

- **レール** - スプライン補間（セントリペタルCatmull-Rom）した2Dレール上の質点運動。位置エネルギー $mgh$ ⇄ 運動エネルギー $\frac{1}{2}mv^2$ の変換、動摩擦 $\mu N$、遠心力による離脱（コースアウト）判定。プリセット「おおきなループ」「ジャンプだい」「コースター」と、指で自由に描く「おえかき」
- **ばしょ（重力切替）** - 🌍 ちきゅう（1.0g）／🌙 おつきさま（0.16g）／🚀 うちゅう（無重力）で、飛び方・落ち方を比較
- **ゆか（摩擦切替）** - ❄️ こおり（ツルツル）／🛣️ ふつう／🏖️ すなば（ザラザラ）で減速具合を比較
- **コースアウト判定** - ループ頂点などで「遠心力が重力に負ける（レール法線力が負になる）」と玉がレールを離れて落下。離脱後は放物運動
- **ちからを みる** - 速度・重力・遠心力のベクトル矢印を表示。左に位置／運動エネルギーの棒グラフ（摩擦で合計が目減り＝熱）
- レールはドラッグに追従して再構築。曲率はpxで真円になるよう補正（W≠Hでも楕円化しない）

## 📦 共通ライブラリ（common/）

### storage.js
localStorageのCRUD操作を提供。Cookie→localStorage移行機能付き。

```javascript
const storage = createStorage('keyName', defaultValue);
storage.save(data);
const data = storage.load();
```

### themes.css
CSS変数でテーマカラーを定義。各アプリで共通利用。

### theme-switcher.js
テーマ切り替えUIを提供。

```javascript
ThemeSwitcher.init('selectElementId', {
    defaultTheme: 'white',
    storageKey: 'appTheme'
});
```
